# 개편 지침: 모든 인물을 러시아인으로 (2027 개편)

이미 끝난 것: 이름 교체(격변화 반영). 남은 것: 민족·종교·외국어 요소를 러시아(지방 출신) 설정으로 바꾸기.

## 새 설정 (정본)

### 마리나 로마노브나 키릴로바 (Мари́на Рома́новна Кири́ллова) — 구 니고라
- 41세 전후, 간호사(병원 교대 근무), 싱글맘. **아스트라한 출신 러시아인**. 2004년 간호 전문학교 진학차 모스크바로, 2012년 7번 건물 집을 사서 혼자 입주(할머니의 양탄자를 혼자 계단으로).
- 모국어는 러시아어. '러시아어가 서툴다/성(性) 구분이 어렵다/집에선 우즈베크어' 같은 설정은 모두 삭제 → 대신 **지방 출신이라 모스크바에서 '남의 사람(не своя́)' 취급을 받는 느낌**, 남부 억양, 바쁜 교대 근무.
- 여권 검사·국적 취득·이주민 규정 관련 이야기는 삭제하거나 '지방 출신·임시 등록(временная регистра́ция)' 문제(과거 셋방살이 시절)로 바꾼다.
- 부모: **로만 페트로비치**(1958년생, 1979~80년 아스트라한 콤소몰 건설대로 모스크바 올림픽 선수촌 건설에 참여, 사진·기념 배지), **갈리나**(어머니). 둘 다 아스트라한 거주. 할아버지는 아스트라한 근교 시골 학교 수학 교사.
- 음식: 플롭·삼사·우즈베크 요리 → **아스트라한 요리**: 우하(уха́), 생선 파이(ры́бник, пиро́г с ры́бой), 말린 보블라(во́бла), 아스트라한 수박·토마토. 타슈켄트 시장 '초르수' → 아스트라한 시장 **'Больши́е Иса́ды'**. 우즈베크 찻잔(пиала́) → **할머니의 금테 찻잔(ча́шки с золоты́м ободко́м)**. 살구나무 → 바바 할머니 마당의 **사과나무**.
- 쿠르반 바이람 → **5월 16일 마리나의 생일**(같은 날짜 그대로, 생선 파이 잔치). 무슬림 관련 언급은 삭제.
- 루스탐의 튜베테이카(티무르에게 준 것, 9/1 주머니) → **할아버지 로만의 '올림픽-80 건설자' 배지**(미샤 곰 배지). 배지는 주머니에.

### 티무르 키릴로프 (Тиму́р Кири́ллов)
- 이름 그대로(러시아에서도 흔한 이름, 가이다르의 『티무르와 그의 팀』). 러시아어 모국어. 외할머니 집은 아스트라한.

### 표도르 (Фёдор, 말할 때는 «Фёдор»/«Фе́дя») — 구 파르호드
- 40세 전후, **볼로그다주 토티마(То́тьма) 출신 러시아인**. 2019년 모스크바로 와 배달원 → 마당 관리인 → 8월부터 '쥘리시니크' 2동 관리인. 아내와 아들이 모스크바에 있음.
- 두샨베·후잔트 → **토티마·볼로그다**. 타지크 춤 → **〈바리냐〉 춤/볼로그다 차스투시카**. 아내의 삼사 → **아내의 샨기(ша́ньги)·생선 파이**. «Ассала́му але́йкум» → «Здоро́во!». '알라' → «Го́споди». 이주 노동 허가(патент) → **비공식 고용·근로 계약 없는 배달 일, 밀린 임금** 문제로.
- 할머니(후잔트) → **토티마의 할머니**. '6년 전 첫 월급이 밀려 사흘 굶었을 때 팔르이치가 먹여 준' 이야기는 유지.

### 알료나 이고레브나 골루베바 (Алёна И́горевна Голубе́ва) — 구 아이굴
- 30세, 동네 약국 약사, **키로프(뱌트카) 출신 러시아인**, 3번 현관 5층 리디야 미하일로브나 집 세입자. 할머니 **마리야 스테파노브나**(80세, 키로프주 **슬로보드스코이** 거주). 이모 **라야**(슬로보드스코이).
- 사반투이(60화) → **콜로멘스코예의 민속 축제 «Ру́сское по́ле»**(벨트 씨름 борьба́ на поя́сах, 기둥 오르기, 자루 달리기). 쿠라시 → **벨트 씨름**, 졔냐는 벨트 씨름 클럽에서 연습(친구 **글레프**).
- 에치포치마크 → **뱌트카식 샨기·피로크**, 착착 → **꿀 바른 흐보로스트(хво́рост с мёдом)**, 칼파크 → **할머니의 숄**, 타타르 춤곡 → **〈카마린스카야〉**. 니카흐 → **10월, 슬로보드스코이 시골 교회에서 혼배성사(венча́ние)**. 모스크 → 교회. 카잔 → 키로프. 아르스크 꿀 → **뱌트카 꿀**. '슬라브인만'이라는 차별 광고 → **'모스크바 사람만, 지방 출신 사절'** 광고.
- 할머니의 평가 «Годи́тся»(최고점), 그 위 «Отли́чно» — 이미 러시아어로 되어 있으니 유지.

### 기타
- 마카르(구 마라트, 카탸의 전 동료), 스네자나(구 사비나), 글레프(구 일다르) — 이름만 바뀜, 민족 언급이 있으면 삭제.
- 외국어 단어·문장(우즈베크어·타지크어·타타르어·아랍어 인사·기도 등)은 러시아어 텍스트에 **하나도 남기지 않는다**. 지명(예레반 등)은 장소 이름이라 유지해도 된다.
